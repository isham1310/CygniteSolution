# CyniteTech

**CyniteTech** is a modern technology and software services website developed using **HTML, CSS, and JavaScript**. The website presents digital solutions and services while providing interactive features such as internship information, certificate verification, customer testimonials, contact functionality, and an AI Assistant.

## 🚀 Features

* Modern dark-themed responsive UI
* Home page with company introduction and call-to-action
* About Us section
* Technology and digital services section
* Internship information section
* Testimonials section
* **Certificate Verification** functionality
* Contact form for customer inquiries
* Interactive navigation
* **AI Assistant / Chatbot** for answering user queries
* Responsive design for different screen sizes
* Social media and useful navigation links

## 🛠️ Technologies Used

* **HTML5** – Website structure
* **CSS3** – Styling, layout, responsive design and UI
* **JavaScript** – Interactivity and dynamic functionality
